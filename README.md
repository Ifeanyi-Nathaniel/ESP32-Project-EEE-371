# ESP32 LED Display — Time, Temperature & Humidity Panel

*Course: EEE371 (Logic Design & Digital Circuits) · Lecturer: Dr. Dauda · Group project*

> This repository is a fork of the original class group project, preserved here to document and reference my individual contribution as a member of the team.

# Overview
A L.E.D Display with an embedded time, temperature and humidity sensor programmed to display the current temperature in cycles, It can be remotely turned on/off via a web dashboard at (http://192.168.1.1), the dashboard can be used to toggle between 3 modes:
- Time
- Temperature
- Text

# My Contribution

As part of this group project, my responsibilities and contributions included:

- **Hardware procurement** — Funded the purchase of the ESP32 microcontroller and other core electronic components used to build the final prototype.
- **Microcontroller selection research** — Researched and evaluated alternative microcontroller options against the project's requirements, and helped the team determine that the ESP32 was the best fit for the design based on its Wi-Fi connectivity, I/O requirements, cost, and processing needs.
- **Project defense** — Represented the team during the in-class project defense, presenting the work to Dr. Dauda and responding to technical questions on the design and implementation.
